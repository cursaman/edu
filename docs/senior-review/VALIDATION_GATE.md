# 시니어 과정 검증 관문

## 신규 과정 추가 조건

다음 조건을 모두 만족해야 신규 과정 3개를 플랫폼에 공개합니다.

1. 실제 시니어 개발자 리뷰가 최소 2건 도착한다.
2. React 리뷰 1건과 보안 또는 결제 리뷰 1건 이상을 포함한다.
3. 치명적 문제는 0건이어야 한다.
4. 중요 문제는 모두 수정하고 같은 재현 절차로 다시 검사한다.
5. React 시작·완성 프로젝트의 테스트와 빌드가 모두 성공한다.
6. 성능 측정은 결과 개수가 동일하고 3회 중앙값을 기록한다.
7. 비밀 키·비밀번호·실제 개인정보가 Git과 ZIP에 없음을 확인한다.
8. 수정된 회차는 원 리뷰어 또는 동급 검토자 1명이 재검토한다.

## 판정

- `공개 가능`: 위 조건을 모두 충족
- `수정 후 재검토`: 중요 문제 또는 실행 실패가 남음
- `공개 보류`: 치명적 보안·결제 오류, 재현 불가능한 결과 또는 검토자 부족
