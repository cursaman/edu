# 검증 후 추가할 시니어 신규 과정 3개

이 문서는 설계안이며 아직 EDU 프로그램 데이터에 등록하지 않습니다.

## 1. 프런트엔드 테스트·성능 엔지니어링

- 결과물: 성능 예산, 자동 테스트와 회귀 대시보드를 갖춘 React 프로젝트
- 12회차 후보: 측정 기준, Web Vitals, React Profiler, 목록 가상화, 네트워크·캐시, 번들 분석, 접근성 자동화, 단위 테스트, 통합 테스트, E2E, CI 품질 관문, 성능 사고 회고
- 선행 조건: React 리팩터링 실무 검증 통과

## 2. Node.js API 아키텍처와 운영

- 결과물: 입력 검증·관측성·장애 격리가 적용된 운영형 REST API
- 12회차 후보: 계층 경계, API 계약, 검증, 오류 모델, 트랜잭션, 동시성, 캐시, 작업 큐, 요청 제한, 구조화 로그, 부하 테스트, 운영 인수
- 선행 조건: 결제 과정의 멱등성·부분 실패 회차 검증 통과

## 3. CI/CD·관측성·장애 대응

- 결과물: 테스트·단계 배포·모니터링·롤백과 장애 런북을 갖춘 배포 파이프라인
- 12회차 후보: 배포 전략, CI 테스트, 비밀 관리, Preview 환경, DB 변경, 기능 플래그, 로그, 메트릭, 추적, 경보, 장애 훈련, 사후 분석
- 선행 조건: React 빌드·성능 결과와 결제·RLS 운영 점검 검증 통과

## 등록 보류 이유

기존 3개 시니어 과정에 대한 실제 개발자 피드백이 없으면 신규 과정도 같은 품질 문제를 반복할 수 있습니다. 리뷰 결과에서 반복되는 요구를 먼저 반영하고 과정별 실습 파일과 평가 기준을 확정한 후 등록합니다.
