# React 웹사이트 만들기 — 강사용 수업 지도서

> 과정 전체 30회차를 실제 수업처럼 진행하기 위한 지도서입니다. 수업 전에 예제와 다운로드 파일을 직접 실행하고, 실제 소요 시간과 반복 질문을 기록합니다.

## 공통 운영 원칙

- 완성 코드를 먼저 보여주지 않고 학습자가 실행 결과를 예상하게 합니다.
- 오류가 발생하면 대신 고치기 전에 첫 오류 문장, 파일, 줄 번호, 재현 순서를 말하게 합니다.
- 빠른 학습자에게는 경계값 실습을, 늦은 학습자에게는 최소 완료 범위를 제공합니다.
- 실제 개인정보·비밀번호·API 비밀 키를 실습에 사용하지 않습니다.
- 회차가 끝나면 예정 시간, 실제 시간, 완료 인원, 반복 질문과 수정 사항을 기록합니다.

## 1회차 · 개발 환경과 첫 화면 실행

- 주차: 1주차
- 예정 시간: 50분
- 학습 목표: Node.js·npm·Vite의 역할을 알고 프로젝트를 실행합니다.
- 완성 결과: 내 문구가 표시되는 첫 React 화면

### 강사가 말할 핵심 설명

Vite 개발 서버를 실행하고 App.jsx 문구를 수정해 저장과 화면 갱신 흐름을 확인합니다. 완성 파일을 먼저 복사하지 말고 시작 파일에서 한 단계씩 수정한 뒤 브라우저 또는 터미널 결과를 확인하게 합니다.

### 수업 진행

- **0~5분** 지난 회차 확인과 오늘 만들 결과 소개
- **5~15분** 개발 환경과 첫 화면 실행 핵심 개념을 쉬운 예로 설명
- **15~35분** 예제 실행 후 내 프로젝트에 맞게 수정
- **35~45분** 오류 해결과 PC·모바일 결과 확인
- **45~50분** 확인 문제, 과제 안내, 학습 완료 표시

### 시연 코드

```text
npm install
npm run dev
```

### 실습 진행 순서

1. 터미널에서 node -v와 npm -v를 실행해 버전 번호를 확인합니다.
2. 연습 폴더에서 npm create vite@latest react-day7-practice -- --template react를 실행합니다.
3. 생성된 폴더로 이동해 npm install과 npm run dev를 차례로 실행합니다.
4. src/App.jsx를 1회차 시작 파일 내용으로 바꾸고 제목을 자신의 문구로 수정합니다.
5. 터미널의 Local 주소를 열고 저장 전후 화면과 첫 오류 문장을 활동지에 기록합니다.

### 정상 실행 결과

1. 수정한 제목과 설명이 첫 화면에 표시됩니다.
2. 터미널의 로컬 주소와 실행 명령을 설명할 수 있습니다.

### 자주 발생하는 오류와 대응

1. node 또는 npm 명령을 찾지 못하면 Node.js 설치 후 터미널을 완전히 닫고 다시 엽니다.
2. package.json을 찾지 못하면 cd 명령으로 react-day7-practice 폴더에 들어왔는지 확인합니다.
3. 화면이 비면 src/App.jsx 저장 여부와 터미널·브라우저 콘솔의 첫 번째 오류를 확인합니다.

### 확인 질문과 정답

1. **질문:** 로컬 주소가 열리나요?
   **정답 예시:** npm run dev 뒤에 표시된 Local 주소가 브라우저에서 열리면 정상입니다.
2. **질문:** 수정한 제목이 보이나요?
   **정답 예시:** src/App.jsx의 h1 문구를 수정하고 저장하면 새 제목이 표시됩니다.

### 완료·평가 기준

1. 3점: 회차의 핵심 React 또는 CSS 기능이 동작합니다.
2. 2점: 예제를 자신의 교육 주제로 수정했습니다.
3. 2점: 정상 화면과 오류 상태를 확인했습니다.
4. 2점: 완성 파일과 차이를 설명했습니다.
5. 1점: 결과와 배운 점을 기록했습니다.

## 2회차 · JSX와 컴포넌트 이해

- 주차: 1주차
- 예정 시간: 50분
- 학습 목표: 반복되는 화면을 재사용 가능한 컴포넌트로 나눕니다.
- 완성 결과: 재사용 가능한 헤더 컴포넌트

### 강사가 말할 핵심 설명

Header와 MainContent를 함수 컴포넌트로 나눠 JSX 화면 부품의 역할을 구분합니다. 완성 파일을 먼저 복사하지 말고 시작 파일에서 한 단계씩 수정한 뒤 브라우저 또는 터미널 결과를 확인하게 합니다.

### 수업 진행

- **0~5분** 지난 회차 확인과 오늘 만들 결과 소개
- **5~15분** JSX와 컴포넌트 이해 핵심 개념을 쉬운 예로 설명
- **15~35분** 예제 실행 후 내 프로젝트에 맞게 수정
- **35~45분** 오류 해결과 PC·모바일 결과 확인
- **45~50분** 확인 문제, 과제 안내, 학습 완료 표시

### 시연 코드

```text
function Header() {
  return <header><h1>EDU</h1></header>
}
export default Header
```

### 실습 진행 순서

1. react-day7-practice 폴더를 열고 src/App.jsx를 App-before-lesson-02.jsx로 복사해 백업합니다.
2. 2회차 시작 파일을 src/App.jsx에 붙여 넣고 화면을 확인합니다.
3. Header와 MainContent를 별도 함수로 작성해 제목과 본문을 나눕니다.
4. 두 컴포넌트를 App에서 <Header />와 <MainContent />로 호출합니다.
5. 완성 파일과 비교하고 함수 이름·호출 위치·화면 결과를 활동지에 기록합니다.

### 정상 실행 결과

1. Header와 본문이 별도 함수에서 표시됩니다.
2. 컴포넌트 이름·export·호출 관계가 올바릅니다.

### 자주 발생하는 오류와 대응

1. 화면이 비면 터미널과 브라우저 콘솔의 첫 번째 오류, 파일 저장 여부를 확인합니다.
2. import 또는 컴포넌트 오류가 나면 파일명·경로·대소문자·export를 확인합니다.
3. 화면은 나오지만 동작하지 않으면 이벤트 함수와 상태 변경 위치를 확인합니다.

### 확인 질문과 정답

1. **질문:** 컴포넌트 이름이 대문자로 시작하나요?
   **정답 예시:** React가 일반 HTML 태그와 구분할 수 있도록 컴포넌트 이름은 대문자로 시작합니다.
2. **질문:** export와 import가 연결됐나요?
   **정답 예시:** 같은 파일에서는 import가 필요 없고, 별도 파일로 분리할 때 export와 import를 연결합니다.

### 완료·평가 기준

1. 3점: 회차의 핵심 React 또는 CSS 기능이 동작합니다.
2. 2점: 예제를 자신의 교육 주제로 수정했습니다.
3. 2점: 정상 화면과 오류 상태를 확인했습니다.
4. 2점: 완성 파일과 차이를 설명했습니다.

## 5회차 · 상태로 분야 필터 만들기
