# 웹 기초부터 첫 홈페이지 만들기 — 강사용 수업 지도서

> 과정 전체 30회차를 실제 수업처럼 진행하기 위한 지도서입니다. 수업 전에 예제와 다운로드 파일을 직접 실행하고, 실제 소요 시간과 반복 질문을 기록합니다.

## 공통 운영 원칙

- 완성 코드를 먼저 보여주지 않고 학습자가 실행 결과를 예상하게 합니다.
- 오류가 발생하면 대신 고치기 전에 첫 오류 문장, 파일, 줄 번호, 재현 순서를 말하게 합니다.
- 빠른 학습자에게는 경계값 실습을, 늦은 학습자에게는 최소 완료 범위를 제공합니다.
- 실제 개인정보·비밀번호·API 비밀 키를 실습에 사용하지 않습니다.
- 회차가 끝나면 예정 시간, 실제 시간, 완료 인원, 반복 질문과 수정 사항을 기록합니다.

## 1회차 · 웹과 개발 환경 · 개념 이해

- 주차: 1주차
- 예정 시간: 50분
- 학습 목표: 웹과 개발 환경의 역할과 필요한 이유를 설명합니다.
- 완성 결과: 웹과 개발 환경 개념 이해 결과물

### 강사가 말할 핵심 설명

파일을 더블클릭했을 때 브라우저가 열리는 모습을 먼저 보여주세요. HTML은 어려운 명령어가 아니라 브라우저에 전달하는 내용표라는 점을 강조합니다. 수강생이 제목을 직접 바꾸고 저장·새로고침의 차이를 말하게 합니다.

### 수업 진행

- **0~5분** 지난 회차 확인과 오늘 만들 결과 소개
- **5~15분** 웹과 개발 환경 · 개념 이해 핵심 개념을 쉬운 예로 설명
- **15~35분** 예제 실행 후 내 프로젝트에 맞게 수정
- **35~45분** 오류 해결과 PC·모바일 결과 확인
- **45~50분** 확인 문제, 과제 안내, 학습 완료 표시

### 시연 코드

```text
<!-- 브라우저는 위에서 아래로 HTML을 읽습니다. -->
<h1>나의 첫 웹페이지</h1>
<p>브라우저가 HTML을 읽어 이 문장을 표시합니다.</p>
```

### 실습 진행 순서

1. 시작 파일을 내려받아 연습용 폴더에 저장합니다.
2. 파일을 더블클릭해 Chrome에서 열고 현재 빈 화면을 확인합니다.
3. 주석 아래에 <h1>나의 첫 웹페이지</h1>과 설명 문단 <p>브라우저가 HTML을 읽어 이 문장을 표시합니다.</p>를 작성합니다.
4. Ctrl+S로 저장한 뒤 브라우저를 새로고침해 제목과 설명이 나타나는지 확인합니다.
5. 완성 파일과 비교하고 파일명·저장 위치·화면을 활동지에 기록합니다.

### 정상 실행 결과

1. 브라우저 탭 제목이 “나의 첫 웹페이지”로 표시됩니다.
2. 화면에 큰 제목과 설명 문단이 한 번씩 표시됩니다.
3. 파일을 수정하고 저장한 뒤 새로고침하면 문구가 바뀝니다.

### 자주 발생하는 오류와 대응

1. 화면이 그대로면 편집기에서 Ctrl+S로 저장했는지 확인합니다.
2. 코드가 글자로 보이면 파일 확장자가 .html인지 확인합니다.
3. 다른 파일이 열리면 주소창 끝의 파일명과 저장 위치를 확인합니다.

### 확인 질문과 정답

1. **질문:** HTML 파일을 화면으로 해석하는 프로그램은 무엇인가요?
   **정답 예시:** Chrome 같은 웹브라우저입니다.
2. **질문:** 이번 개념 이해 회차에서 직접 확인한 결과는 무엇인가요?
   **정답 예시:** 웹과 개발 환경 개념 이해 결과물
3. **질문:** 오류가 생겼을 때 먼저 기록할 정보는 무엇인가요?
   **정답 예시:** 실행 명령·브라우저 주소·재현 순서와 첫 번째 오류 문장입니다.

### 완료·평가 기준

2. 3점: h1과 p 문구를 직접 수정했습니다.
3. 2점: 저장과 새로고침의 관계를 설명했습니다.
4. 2점: 완성 화면과 파일 위치를 기록했습니다.

완성된 태그를 먼저 설명하지 말고, head는 보이지 않는 문서 정보이고 body는 사용자에게 보이는 내용이라는 생활 비유로 구분합니다. 태그 하나를 추가할 때마다 브라우저에서 바로 확인하게 합니다.

### 수업 진행

- **0~5분** 지난 회차 확인과 오늘 만들 결과 소개

- **45~50분** 확인 문제, 과제 안내, 학습 완료 표시

### 시연 코드

```text
<!doctype html>
<html lang="ko"><body><h1>첫 웹페이지</h1></body></html>
```

### 실습 진행 순서

1. 2회차 시작 파일을 내려받고 Chrome에서 엽니다.
2. title을 “우리 동네 배움터”로 수정합니다.
3. header와 main을 만들고 기존 제목과 설명을 알맞은 영역으로 옮깁니다.
4. h2와 ul·li로 오늘 배울 내용 세 개를 작성합니다.
5. 완성 파일과 태그 구조를 비교하고 들여쓰기를 정리합니다.

### 정상 실행 결과

1. 브라우저 탭과 h1에 서로 알맞은 제목이 표시됩니다.
2. header와 main 안에 내용이 의미에 맞게 구분됩니다.
3. 세 개의 학습 항목이 글머리표 목록으로 표시됩니다.

### 자주 발생하는 오류와 대응

1. 일부 내용이 사라지면 여는 태그와 닫는 태그의 짝을 위에서부터 확인합니다.
2. 한글이 깨지면 meta charset이 UTF-8인지 확인합니다.
3. 목록 모양이 이상하면 ul 안에 li가 들어 있는지 확인합니다.

2. **질문:** 이번 따라 하기 회차에서 직접 확인한 결과는 무엇인가요?
   **정답 예시:** 웹과 개발 환경 따라 하기 결과물
3. **질문:** 오류가 생겼을 때 먼저 기록할 정보는 무엇인가요?
   **정답 예시:** 실행 명령·브라우저 주소·재현 순서와 첫 번째 오류 문장입니다.

## 4회차 · HTML 문서 구조 · 개념 이해

- 주차: 2주차
- 예정 시간: 50분
- 학습 목표: HTML 문서 구조의 역할과 필요한 이유를 설명합니다.
- 완성 결과: HTML 문서 구조 개념 이해 결과물

### 강사가 말할 핵심 설명

HTML 문서의 head와 body를 구분하고 문자 인코딩·화면 너비·탭 제목 정보를 작성합니다. 완성 파일을 먼저 보여주지 말고 시작 파일에서 태그를 하나씩 추가할 때마다 저장과 새로고침을 반복하게 합니다.

### 수업 진행

- **0~5분** 지난 회차 확인과 오늘 만들 결과 소개
- **5~15분** HTML 문서 구조 · 개념 이해 핵심 개념을 쉬운 예로 설명
- **15~35분** 예제 실행 후 내 프로젝트에 맞게 수정
- **35~45분** 오류 해결과 PC·모바일 결과 확인
- **45~50분** 확인 문제, 과제 안내, 학습 완료 표시

### 시연 코드

```text
<!doctype html>
<html lang="ko">
<head></head>
<body></body>
</html>
```

### 실습 진행 순서

1. 04회차 시작 파일을 내려받아 이전 회차 폴더와 분리해 저장합니다.
2. HTML 문서의 head와 body를 구분하고 문자 인코딩·화면 너비·탭 제목 정보를 작성합니다.
3. 예제의 문구나 항목 한 가지를 자신의 주제로 바꿉니다.
4. Chrome에서 정상 화면과 잘못 작성한 경우를 비교합니다.
5. 완성 파일과 비교한 뒤 다른 부분과 배운 점을 기록합니다.

### 정상 실행 결과

1. head에는 보이지 않는 문서 정보, body에는 화면 내용을 작성했습니다.
2. 한글과 모바일 화면에 필요한 meta 태그가 있습니다.

### 자주 발생하는 오류와 대응

1. 화면이 비거나 일부만 나오면 태그의 여는 부분과 닫는 부분을 위에서부터 확인합니다.
2. 한글이 깨지거나 모바일이 넓게 보이면 charset과 viewport meta 태그를 확인합니다.
3. 링크나 이미지가 동작하지 않으면 href·src의 경로와 따옴표를 확인합니다.

### 확인 질문과 정답

1. **질문:** 사용자에게 보이는 내용은 어느 태그 안에 작성하나요?
