# 21회차 완성 — 4주 작업 지도

| 주차 | 핵심 작업 | 보여줄 결과 | 완료 기준 |
|---|---|---|---|
| 1주 | 홈·조건 입력 화면 | PC·모바일 첫 화면 | 세 조건을 키보드로 입력 가능 |
| 2주 | 추천 규칙·결과 카드 | 결과 세 개 | 같은 입력은 같은 결과를 표시 |
| 3주 | 최근 결과·오류 상태 | 저장과 복구 화면 | 새로고침 후 최근 결과 유지 |
| 4주 | 테스트·배포·발표 | 실제 공개 URL | 다른 기기에서 핵심 흐름 통과 |

각 주 마지막에 동작하는 작은 결과가 있어야 하며, 미완료 기능은 다음 주 필수 작업으로 자동 이동시키지 않고 범위를 다시 판단합니다.
