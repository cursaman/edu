# 15회차 완성 — 개선 사용자 여정

| 단계 | 사용자 행동 | 서비스 반응 | 성공 기준 |
|---|---|---|---|
| 1 | 지역·시간·취향 입력 | 입력값 확인 | 1분 안에 입력 완료 |
| 2 | 추천 요청 | 활동 3개 표시 | 3초 안에 결과 표시 |
| 3 | 이유·시간 비교 | 같은 카드 형식 제공 | 탭 이동 없이 비교 |
| 4 | 하나 선택 | 상세 링크 제공 | 사용자가 선택 이유 설명 |
| 5 | 최근 결과 확인 | 브라우저에 보관 | 새로고침 후 다시 확인 |

추천이 결정하는 것이 아니라 사용자가 비교하고 선택하도록 설계합니다.
