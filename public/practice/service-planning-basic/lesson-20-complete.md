# 20회차 완성 — 요구사항과 완료 기준

```text
기능: 조건 입력
사용자 이야기: 주말 활동을 찾는 사람으로서 내 상황에 맞는 세 결과를 보기 위해 지역·시간·취향을 입력하고 싶다.
입력: 지역 1~30자, 시간 선택, 취향 1개 이상
처리: 앞뒤 공백 제거, 필수값과 길이 검사
출력: 조건에 맞는 활동 카드 3개
오류: 빈 지역은 입력 아래에 “지역을 입력해 주세요” 표시
완료 기준:
1. 키보드만으로 세 조건을 입력하고 제출할 수 있다.
2. 잘못된 값은 요청 전에 항목별로 안내된다.
3. 정상 제출 시 3초 안에 카드 세 개 또는 결과 없음 안내가 보인다.
4. 360px 화면에서 가로 스크롤이 없다.
```
