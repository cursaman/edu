# 10회차 완성 — 첫 MVP 범위

| 구분 | 기능 | 완료 기준 |
|---|---|---|
| 필수 | 지역·시간·취향 입력 | 세 항목을 키보드로 입력할 수 있다. |
| 필수 | 활동 세 개 표시 | 제목·이유·예상 시간이 카드에 보인다. |
| 필수 | 모바일 화면 | 360px에서 가로 스크롤 없이 읽힌다. |
| 있으면 좋음 | 최근 결과 | 같은 브라우저에서 다시 볼 수 있다. |
| 제외 | 회원가입·결제·관리자 | 첫 사용자 검증 후 판단한다. |

4주 일정에 들어가지 않는 기능은 “나중” 목록으로 옮깁니다. MVP는 작은 완성품이지 기능 일부가 고장 난 큰 서비스가 아닙니다.
