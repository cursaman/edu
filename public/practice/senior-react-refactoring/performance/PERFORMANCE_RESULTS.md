현재 환경의 중앙값 기준으로 개선 후 함수가 약 19.9% 빨랐습니다. 주된 차이는 반복문 안에서 매 항목마다 검색어를 정리하던 작업을 반복문 밖에서 한 번만 수행한 것입니다.

첫 측정에서는 개선 코드에 `toLocaleLowerCase('ko-KR')`를 사용해 오히려 약 22배 느려지는 회귀가 발견됐습니다. 한국어 제목 검색에는 해당 로케일 변환이 필요하지 않아 `toLowerCase()`로 수정하고 다시 측정했습니다. 이 기록은 “최적화는 추측하지 말고 측정한다”는 실습 사례로 유지합니다.

```bash
npm run perf
```

숫자는 컴퓨터 상태와 Node.js 버전에 따라 달라집니다. 최소 3번 실행하여 중앙값을 비교하고 검색 결과 개수가 같은지도 확인해야 합니다.
