# 25회차 완성 — 컴포넌트 동작 설명

| 요소 | 열기 | 닫기 | 초점 |
|---|---|---|---|
| 모바일 메뉴 | 버튼 Enter·클릭 | 항목 선택·Esc·바깥 클릭 | 첫 항목 이동 → 버튼 복귀 |
| 필터 패널 | 필터 버튼 | 적용·초기화·Esc | 첫 필터 이동 → 버튼 복귀 |
| 과정 펼치기 | 제목 버튼 | 같은 버튼 | 버튼에 유지 |
| 확인 모달 | 삭제 버튼 | 취소·Esc | 모달 안 이동 → 삭제 버튼 복귀 |

상태 변화 시간, 결과 문장과 감소된 모션에서의 동작도 개발 주석에 적습니다.
