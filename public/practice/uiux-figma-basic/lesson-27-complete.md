# 27회차 완성 — 접근성 개발 주석

```text
Landmark: header / nav / main / footer
제목: H1 프로그램 상세 → H2 학습 목표 → H3 각 목표
대표 이미지 alt: 노트북으로 반응형 홈페이지를 확인하는 성인 학습자
검색 label: 교육 프로그램 검색
필터 결과: aria-live polite로 “12개 결과” 안내
모바일 메뉴: aria-expanded와 aria-controls 연결
장식 아이콘: 스크린리더에서 숨김
```

색상 대비 수치와 키보드 초점 순서를 화면 번호와 함께 기록합니다.
