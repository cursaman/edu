# 4회차 완성 — 기본 색상 정하기

| 역할 | 예시 | 사용 위치 |
|---|---|---|
| Primary | `#5B63FF` | 주요 버튼·현재 메뉴 |
| Secondary | `#55C7B5` | 보조 정보·완료 상태 |
| Accent | `#FF7D6B` | 제한적인 강조 |
| Text | `#172033` | 제목·본문 |
| Background | `#F7F8FC` | 페이지 배경 |
| Surface | `#FFFFFF` | 카드·입력 영역 |

색상 스타일 이름을 `Color/Primary/500`처럼 역할 중심으로 저장합니다. 강조색은 작은 부분에만 사용합니다.
