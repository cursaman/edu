# 11회차 완성 — 텍스트 입력 컴포넌트

```text
Field / Text / Default
Field / Text / Focus
Field / Text / Filled
Field / Text / Disabled
```

- Label: 입력칸 위에 항상 표시
- 입력 높이: 최소 48px
- 좌우 여백: 16px
- 도움말: 입력 목적과 형식 설명
- Placeholder: 예시로만 사용하고 Label을 대신하지 않음
- Focus: 배경과 구분되는 테두리 표시

긴 Label과 200% 확대에서도 글자가 잘리지 않는지 확인합니다.
