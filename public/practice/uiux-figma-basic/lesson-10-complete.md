# 10회차 완성 — 버튼 컴포넌트

버튼 Component Set 예시:

```text
Button / Primary / Default
Button / Primary / Hover
Button / Primary / Focus
Button / Primary / Disabled
Button / Secondary / Default
```

- 높이: 최소 44px
- 좌우 여백: 20px
- 글자: 16px, 600
- Focus: 배경과 구분되는 2px 이상 테두리
- Disabled: 흐리게 표시하고 클릭 불가 상태 설명

아이콘만 있는 버튼에는 개발 전달 시 접근 가능한 이름을 적습니다.
