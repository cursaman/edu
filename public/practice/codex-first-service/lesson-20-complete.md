# 20회차 완성 — 오류 수정 요청

```text
교육자료 검색 후 상세 화면이 백지로 나오는 문제를 진단하고 수정해줘.

재현:
1. 홈 → 교육자료
2. “React” 검색
3. 첫 카드 선택
4. 백지 화면 발생

기대: 선택한 React 자료 상세가 표시됨
실제: 전체 화면이 비고 콘솔에 “Cannot read properties of undefined”
최근 변경: 검색 결과에 페이지네이션 추가

먼저 Git 상태와 관련 파일을 확인해 원인을 설명한 뒤 최소 범위로 수정해줘. 검색·필터·학습 완료 기능을 유지하고 재현 절차, 없는 ID, 새로고침과 npm run build를 검사해줘.
```
