# 19회차 완성 — localStorage 저장 요청

```text
교육자료 찜 목록을 localStorage에 저장해줘.

- 키: edu-bookmarked-lessons-v1
- 값: 자료 id 문자열 배열만 저장
- 첫 화면에서 안전하게 읽고 없는 키는 빈 배열
- JSON이 깨졌으면 빈 배열로 복구하고 화면은 유지
- 찜 버튼으로 추가·해제, 중복 저장 금지
- 새로고침 후 상태 유지
- 전체 찜 삭제 전 확인

이름·연락처·비밀번호 같은 실제 개인정보는 저장하지 말고 현재 브라우저에만 보인다는 안내를 표시해줘.
```
