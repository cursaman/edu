# 26회차 완성 — GitHub 업로드 요청

```text
현재 검증된 로컬 커밋을 origin main에 업로드해줘.

- git remote -v와 현재 브랜치 확인
- git fetch origin 후 앞섬·뒤처짐 확인
- 원격 변경이 있으면 안전하게 통합하고 충돌은 보고
- force push와 reset --hard 사용 금지
- 인증 정보가 없으면 반복하지 말고 정확한 오류와 사용자가 실행할 명령 보고
- push 후 로컬 HEAD와 origin/main 커밋 일치 확인
- GitHub Actions 실행 여부와 저장소 주소 보고
```
