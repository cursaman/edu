# 16회차 완성 — 사용자 도메인과 DNS

1. Vercel **Project → Settings → Domains**에서 도메인을 추가합니다.
2. Vercel이 안내한 A 또는 CNAME 레코드를 도메인 업체 DNS에 입력합니다.
3. 기존 메일용 MX 레코드는 삭제하지 않습니다.
4. Vercel의 Valid Configuration 표시를 기다립니다.
5. `https://` 접속과 인증서를 확인합니다.
6. 대표 주소가 아닌 쪽은 대표 주소로 이동시킵니다.

DNS 반영에는 시간이 걸릴 수 있으므로 여러 값을 반복 변경하지 않습니다.
