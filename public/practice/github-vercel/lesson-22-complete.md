# 22회차 완성 — SEO와 공유 정보

`index.html`의 기초 예시입니다.

```html
<title>EDU 웹개발 교육 플랫폼</title>
<meta name="description" content="초보자도 직접 만들고 배포하며 배우는 웹개발 교육입니다.">
<meta property="og:title" content="EDU 웹개발 교육 플랫폼">
<meta property="og:description" content="AI와 함께 배우는 실전 웹개발 교육">
<meta property="og:image" content="https://example.com/og-image.webp">
<link rel="canonical" href="https://example.com/">
```

실제 주소와 저작권이 확인된 이미지만 사용합니다.
